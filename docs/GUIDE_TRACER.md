# VHS Tracer — moved

The Tracer has moved out of this VHS repository into the dedicated Tracer project:

- Maintained repository: [utrost/Tracer](https://github.com/utrost/Tracer)

This file is kept only as a migration note so old VHS documentation links do not fail silently. Tracer is no longer runnable from this repository, and VHS no longer contains a `TracerUI/` directory.

For current Tracer setup, usage, and development notes, use the dedicated Tracer repository. VHS now focuses on handwriting glyph capture, assembly, and SVG generation.
