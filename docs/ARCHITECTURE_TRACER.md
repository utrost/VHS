# VHS Tracer architecture — moved

The Tracer architecture has moved out of this VHS repository into the dedicated Tracer project:

- Maintained repository: [utrost/Tracer](https://github.com/utrost/Tracer)

This archived migration note replaces the old in-repo architecture document. Tracer is no longer an in-repo VHS component, and VHS no longer contains a `TracerUI/` directory or runnable Tracer HTML.

For the current architecture, data model, and implementation details, use the dedicated Tracer repository. VHS now focuses on handwriting glyph capture, assembly, and SVG generation.
